# V6 OnePage Engine

```text
raw source
  -> numbered evidence ledger
  -> reviewed and sealed content graph
  -> relationship aggregation
  -> visual grammar selection
  -> two-dimensional composition
  -> deterministic SVG and editable OpenAPI nodes
  -> semantic, geometric and whole-page review
  -> Feishu whiteboard
```

The Skill contains both the workflow and the only executable runtime. This
removes the repository-path mismatch that previously caused local and
cross-Agent runs to select different implementations.

V6 does not inherit historical template runners. Alpha.5 compiles metrics,
processes, trends, architecture, maturity, evidence distributions, comparisons,
risks and controls, causes, actions and roadmaps from semantic relationships.
Geometry cannot delete information or override semantic selection. Capacity is
resolved through aggregation, two-dimensional packing and adaptive canvas size.

Alpha.5 adds an integrity chain across the whole path:

```text
source fingerprint
  -> reviewed draft fingerprint
  -> sealed graph
  -> source-linked composition units
  -> source-linked final SVG groups
  -> editable OpenAPI nodes
  -> Feishu raw-node round trip
```

Coverage is measured at the final visible layer, not at assignment time. The
renderer is prohibited from inventing recommendations, severity, controls or
generic substitute claims. A release candidate must pass both local geometry
checks and a Feishu-side raw/image export review.
